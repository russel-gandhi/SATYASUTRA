How to use this site
  1. Text: paste a forwarded message or claim, press Investigate. You see each step live, then the verdict with its sources. "Cannot tell" is an honest answer.
  2. Link or PDF, Image or video, Voice note: use the other tabs. Image and video checks show tampering signals, never "this is real".
  3. If a call feels like a scam: open Call guard, put the call on speaker, and watch the screen go amber or red.
  4. If private pictures are being shared or threatened: open Private help. It keeps nothing and has a one-tap exit.
  5. After a check: build a shareable Trust report, or delete the stored record of your checks.

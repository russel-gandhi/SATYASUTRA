## Goal

All URLs, keys (by environment variable name), rate limits and thresholds are read from `config/*.yaml`. Source failures are typed
(`Unreachable`, `RateLimited`, `SchemaChanged`, `QuotaExhausted`) so nothing returns an empty list silently.

## Done when

- `pytest tests/unit/test_config.py` passes: valid files load; a missing key, a bad type and an unknown field are rejected with a clear message; secrets are read only from the environment.
- `config/sources.yaml` lists candidate sources with `status: unverified` until a probe has run.

## Notes

No URL or threshold may appear in `src/`. Thresholds carry the model hash they belong to (empty until a model exists).

## Goal

Given a claim, search the Google Fact Check Tools API and return `Evidence` objects with the publisher, rating, review date and passage, tagged with the source tier from `config/sources.yaml`.

## Done when

- `src/satyasutra/sources/factcheck.py` calls `claims:search` using the key from the environment, respects the rate limit and cache TTL in config, and maps each `claimReview` into `Evidence` with a correct `passage_sha256`.
- Quota or schema surprises raise the typed errors from `errors.py` (`QuotaExhausted`, `SchemaChanged`); an empty result is a normal answer, not an error.
- A cache keyed by normalised query text lives in the ledger database area (not in code), with the TTL from config; the second identical query makes no network call, and a test proves it by counting requests at a local server.
- `tests/unit/test_factcheck.py` covers mapping, empty results, 429, malformed body, and the cache.
- `tests/contract/test_live_factcheck.py` (marked contract) searches a real topic and asserts at least one `Evidence` validates.

## Notes

Ratings are free text in many languages. This ticket keeps the publisher's own rating string untouched. Mapping a rating to a verdict label is the verdict-rules ticket (F1-07), not here.

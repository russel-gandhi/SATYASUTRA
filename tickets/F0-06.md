## Goal

`scripts/probe_sources.py` and `GET /health/sources` report, for every configured source, whether it is reachable from this machine right now, with latency, HTTP status and a typed failure reason.

## Done when

- `pytest tests/unit/test_probe.py` passes (probe logic tested against a local test server; fixtures allowed in tests only).
- `python scripts/probe_sources.py` prints a real reachability table from live endpoints, and sources needing a key say `needs key` instead of failing silently.
- `pytest -m contract` runs the same probe against the live internet.

## Notes

The probe result decides which adapters stay in `sources.yaml` (plan Q3). Record the output in `docs/probe_results.md` at close.

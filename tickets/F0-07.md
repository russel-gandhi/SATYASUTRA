## Goal

A check that fails the build if `src/` contains a URL literal, a data file, an import from `tests/`, a demo or mock switch, or a numeric literal inside a comparison. CI runs it with the tests and the ticket check.

## Done when

- `pytest tests/unit/test_no_fixtures.py` passes: each violation type is detected in a temporary tree and a clean tree passes.
- `python scripts/check_no_fixtures.py` exits 0 on this repository.
- `.github/workflows/ci.yml` runs tests, the guard and `forge.py check`.

## Notes

A deliberate exception needs `# forge: allow-literal <reason>` on that line, and the reason is reviewed in the pull request.

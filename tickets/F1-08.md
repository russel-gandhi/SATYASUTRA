## Goal

The no-model fast clock: normalise each post, drop exact repeats through a cache, group near-duplicates with MinHash, and rank clusters by velocity, so only the busiest claims reach the slow path.

## Done when

- `src/satyasutra/fastclock/normalise.py`, `cluster.py` and `velocity.py` exist, with similarity thresholds, shingle size and window lengths read from `config/thresholds.yaml` and `config/runtime.yaml`.
- Posting the same text twice returns the cached result and the second call touches neither Gemini nor Fact Check (asserted by counting calls).
- `python scripts/cluster_live.py --seconds 60` prints the top clusters from the live stream, each with its size and posts per minute.
- `tests/unit/test_fastclock.py` covers normalisation (case, URLs, whitespace, Unicode forms), cluster merge and split, and velocity over a sliding window using timestamps the test generates.
- The thresholds file is populated from a real 5-minute capture, with the capture command and date in a comment; no number is chosen by feel.

## Notes

The fast clock is allowed no model. If a step needs one, it belongs to the slow path.

## Goal

Receive real public posts as they are written, as `Post` records, with the source named on each one.

## Done when

- `src/satyasutra/ingest/jetstream.py` connects to the Jetstream websocket named in `config/sources.yaml`, keeps only post-creation events, and yields validated `Post` objects. Reconnects after a drop and resumes from the last cursor.
- Filters (language codes, minimum text length, optional keywords) come from `config/runtime.yaml`, with no filter values in code.
- `python scripts/tail_posts.py --seconds 20` prints real post text, language and time from the live stream and exits 0 only if at least one post arrived.
- `tests/unit/test_jetstream.py` feeds the parser raw event bytes captured by the test itself from a local websocket server (the event shape is defined by the Jetstream documentation, not invented) and checks: non-post events are skipped, malformed events are counted and skipped, cursor advances.
- `tests/contract/test_live_jetstream.py` (marked contract) receives at least one live post.

## Notes

Posts are public. Handles are not needed for verification, so the `Post` keeps only what the later stages use; do not store more than that. Measure posts per second for a minute and put the number in `docs/ingest_rate.md` (not `probe_results.md`, which the probe regenerates), since it sets the fast-clock budget.
